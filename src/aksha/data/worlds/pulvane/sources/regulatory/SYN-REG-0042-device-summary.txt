Device description
The Pulvane Ring is a finger-worn optical pulse sensor. It uses a pulse window for rhythm
analysis only when accelerometer motion stays below 0.05 g RMS for the whole window. An
accepted window is classed as irregular from the variability of its beat-to-beat intervals.
The ring shows an irregular-rhythm notification only when three of the last five accepted
windows are irregular.

Intended use
To notify adult wearers of pulse patterns suggestive of an irregular rhythm, for follow-up
with a clinician. Not intended to diagnose.
