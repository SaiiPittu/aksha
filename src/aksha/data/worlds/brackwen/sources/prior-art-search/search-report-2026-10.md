# Prior-art search report: compliant grippers (excerpt)

Search run by an outside search service for Brackwen Robotics on 21 Oct 2026. Two publications were returned under the query "compliant wrist lock contact". The searcher's notes are not legal conclusions.

## Hit 1: SYN-PUB-0301 A1

- Office: SYN-Office-1
- Title: Robot wrist with selectable compliance
- Applicant: Quenmoor Automation Ltd
- Priority: SYN-PRI-2021-1104 (4 Nov 2021)
- Filed: 2 Nov 2022 · Published: 11 May 2023
- Status (office register, 2026-10-01): Application published, examination requested
- Link: https://patents.synthetic.example/SYN-PUB-0301

Abstract. A robot wrist carries an elastomer flexure that lets the end effector tilt and translate when it touches an object. A magnetic brake locks the flexure when contact between the gripper and the object is detected, so the object is carried rigidly.

Description (extract). Contact is detected when the wrist force sensor reading first crosses a contact threshold. The brake is released at the place position, after the object has been set down.

Claims (extract).
1. A robot wrist comprising an elastomer flexure between the arm and the end effector, and a brake that locks the flexure.
2. The wrist of claim 1, wherein the brake locks the flexure when contact between the end effector and an object is detected.
